# 0173. The blog index shows its feature card and cadence chart from four posts

On `src/pages/blog/index.astro` the Latest feature card appears only when there are at least four posts. With a handful of posts the list is the whole page, and a latest card above it only shows its first row twice. The publishing cadence chart is shown only when the feature card is: a chart of one or two bars reads as a mistake, and it shares its row with the feature card, so the two arrive together. The blog description in `site.json` names the feed in plain text, and the page replaces "RSS feed" with a Markdown link only in the visible copy, because the meta description reads the same string and must stay plain text.

On a post page (`src/pages/blog/[...slug].astro`) the footer puts the Older link on the left and Newer on the right, so the pair reads oldest to newest in reading direction, like a timeline. Code frames sit a step darker than the tile they are in, as they would on the page: Expressive Code declares its `--ec-*` background variables on `:root`, so `.post-body` (`src/styles/post-body.css`) redeclares them with the page base colour, which wins for everything inside.
