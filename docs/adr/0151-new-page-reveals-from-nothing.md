# 0151. A new page's picture reveals from nothing

When the field binds to a new page, that page's picture appears with a fresh reveal from nothing, not a sweep from the last page's picture. A sweep would first redraw the old picture in the new page's field, where it reads as the old page left behind.

The page counts as still arriving while it shows BLANK waiting for its drawing. When that drawing lands it sweeps in without restarting the reveal, because restarting would blink out whatever the pointer has lit.
