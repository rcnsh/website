# 0195. The nav uses one travelling underline per rail

The top bar (`src/components/TopBar.astro`) marks the current tab and follows the pointer and focus across the tabs. Cross-fading an underline per tab on hover looks busy, and moving anything other than a transform triggers layout.

The home link and the tabs sit in one relatively positioned rail (`data-nav-rail`) with a single underline element (`data-nav-underline`). The rail has `-ml-3`, cancelling the first tab's `px-3` so the wordmark aligns with the page edge. The underline is a fixed 100px wide and is placed with `translate3d(offsetLeft) scaleX(width / 100)`, so moving it is transform-only. `place` sets `jump = !animate || !shown`: when the bar is not already shown, or the placement is not animated (the initial placement, a resize), it is placed under `data-instant`, which drops the transform transition, and `void bar.offsetWidth` forces a reflow before `data-instant` is removed. Tweening from a stale or initial (0,0) position makes the bar fly in from the corner, which reads as a glitch; without the reflow the browser coalesces the style changes and animates the jump anyway. A target tab with no layout box (hidden at this breakpoint) measures as 0,0, so the bar fades to opacity 0 and is marked not shown instead of collapsing into the corner.

The page shows the current tab without script and before the script runs: `[data-nav-rail]:not([data-nav-ready]) [data-nav-active]::after` draws a static underline. The active tab is found by comparing `Astro.url.pathname` after stripping a trailing `/index.html` and trailing slashes, because with `build.format: "file"` the home page's pathname at prerender time is `/index.html`, which `astro dev` never shows.

Below `sm` the tabs are rendered again as a wrapped row under the bar, the active one marked by an `::after` underline, with no travelling bar: touch has no hover for it to follow. The palette trigger beside them is 30px tall and at least 30px wide with its label and ⌘K hidden below `sm`, which is still a fair touch target.
