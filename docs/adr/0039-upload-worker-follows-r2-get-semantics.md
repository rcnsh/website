# 0039. The upload Worker follows R2's get semantics

`workers/upload/src/handler.ts` passes the request's Range and conditional headers straight to R2 `get()` and translates what comes back into the response R2's public endpoint would give.

R2 throws on a range it cannot satisfy, so a `get` error with a Range header answers 416, and without one it rethrows as a real failure. R2 returns an object without a body when a request condition fails, so that answers 304 if `if-none-match` or `if-modified-since` was sent, else 412. A 206 with `Content-Range` is sent only when the request carried a Range header, because `object.range` being set does not mean only part was asked for; this follows Cloudflare's own R2 Worker example.

`span()` (`shared/bucket-http.ts`) turns `object.range` into the bytes served, and `/api/files/download` uses it too, so both answer a suffix range (`bytes=-N`) with the last N bytes and a matching `Content-Range`. It checks range fields with `typeof`, not `in`. R2 returns every range field, unset ones as undefined, so `in` is always true, and a suffix range read as an offset would claim to start at byte 0.

Both readers decide a Range header with the helpers in `shared/bucket-http.ts`, so they answer it alike. `rangeToAsk` hands R2 a header only when it is one valid `bytes` range, rewritten in lowercase with its bounds normalised; a multi-part, reversed, other-unit or malformed header reaches R2 as no range at all and the whole object is served, as RFC 9110 asks. `rangeOutcome` then picks 200, 206 or 416 from the header and the object R2 returned, and a 416 always names the size (`bytes */size`) and carries none of the object's own headers. Only R2's own range refusal (10039) becomes a 416; any other R2 error surfaces. Bounds are capped at `LARGEST_OBJECT` (2^43 bytes), above R2's 5 TiB object limit: an end past it means "to the end", a suffix past it is the whole object, and a start past it can match no object, so it reaches R2 as no range and is refused once R2 has applied the request's preconditions, with the body cancelled unread. Keep the cap at or above R2's largest object, or valid ranges on large files are refused or rewritten.
