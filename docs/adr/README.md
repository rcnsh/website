# Architecture decision records

Why the code is the way it is. Code carries no comments; a decision that would have been a comment is an ADR here.

## Adding one

Take the next free number and write `NNNN-<slug>.md`, starting `# NNNN. Title`. One decision per file, kept short, in the present tense: what the code does and why, naming code by path and symbol, never by line number. Add it to the index below under its subsystem. When a decision changes, edit its ADR to say what is true now; point to a related one as "See ADR-NNNN."
